## Overview
In this guided activity, we'll create a responsive website using Next.js and Tailwind CSS. You'll learn:
- How to set up a Next.js project with Tailwind CSS
- Understanding utility-first CSS principles
- Creating responsive layouts using Flexbox and Grid
- Implementing a theme system
- Building reusable components with Tailwind

## Prerequisites

Before starting, ensure you have:
- Node.js installed (v18 or higher)
- VS Code installed
- Basic understanding of React and CSS

- Clone this repository to your local machine, open the local repository and follow the instructions below.

## Getting Started

1. Install the Tailwind CSS IntelliSense extension:
   - Open VS Code
   - Go to Extensions (Ctrl+Shift+X)
   - Search for "Tailwind CSS IntelliSense"
   - Install the extension by Tailwind Labs
   - Reload VS Code

2. Create a new Next.js project:
```bash
npx create-next-app@latest my-tailwind-app
```

3. During setup, select the following options:
```
Would you like to use TypeScript? Yes
Would you like to use ESLint? Yes
Would you like to use Tailwind CSS? Yes
Would you like to use `src/` directory? No
Would you like to use App Router? Yes
Would you like to use the default import alias (@/*)? No
Would you like to use Turbopack? No
```

4. Navigate to your project directory:
```bash
cd my-tailwind-app
```

## Part 1: Project Structure and Setup

Create the following project structure:

```
my-tailwind-app/
├── app/
│   ├── globals.css         # Global styles and Tailwind imports
│   ├── layout.tsx          # Root layout with navigation
│   ├── page.tsx           # Home page
│   ├── flexgrid/         
│   │   └── page.tsx       # Flexbox and Grid examples
│   └── theming/          
│       └── page.tsx       # Theming examples
└── next.config.js        # Next.js configuration
```

### Setting Up Global Styles

1. Replace the contents of `app/globals.css` with:

```css
@tailwind base;
@tailwind components;

:root {
```

## Part 2: Creating the Layout

Create your root layout by replacing `app/layout.tsx` with:

```typescript
import type { Metadata } from "next";
import { Geist, Geist_Mono } from "next/font/google";
import Link from "next/link";
import "./globals.css";

const geistSans = Geist({
  variable: "--font-geist-sans",
  subsets: ["latin"],
});

const geistMono = Geist_Mono({
  variable: "--font-geist-mono",
  subsets: ["latin"],
});

export const metadata: Metadata = {
  title: "Create Next App",
  description: "Generated by create next app",
};

export default function RootLayout({
  children,
}: Readonly<{
  children: React.ReactNode;
}>) {
  return (
    <html lang="en">
      <body
        className={`${geistSans.variable} ${geistMono.variable} antialiased`}
      >
        {/* Navigation Bar */}
        <nav className="bg-white shadow-md fixed w-full top-0 z-50">
          <div className="container mx-auto px-4">
            <div className="flex justify-between items-center h-16">
              <div className="text-xl font-bold text-blue-600">My Website</div>
              <div className="flex space-x-6 items-center">
                <Link
                  href="/"
                  className="text-gray-600 hover:text-blue-500 transition-colors duration-200"
                >
                  Home
                </Link>
                <Link
                  href="/flexgrid"
                  className="text-gray-600 hover:text-blue-500 transition-colors duration-200"
                >
                  FlexGrid
                </Link>
                <Link
                  href="/theming"
                  className="text-gray-600 hover:text-blue-500 transition-colors duration-200"
                >
                  About
                </Link>
              </div>
            </div>
          </div>
        </nav>
        <main className="pt-16">{children}</main>
      </body>
    </html>
  );
}
```

Let's understand the key Tailwind concepts used in the layout:

1. **Fixed Navigation**:
   - `fixed w-full top-0`: Creates a navigation bar that stays at the top
   - `z-50`: Ensures the navbar stays above other content
   - `shadow-md`: Adds a medium shadow for depth

2. **Responsive Container**:
   - `container mx-auto`: Centers content and sets max-width
   - `px-4`: Adds horizontal padding
   - `flex justify-between`: Creates space between logo and navigation

3. **Navigation Links**:
   - `space-x-6`: Adds horizontal spacing between links
   - `hover:text-blue-500`: Changes text color on hover
   - `transition-colors`: Smooths color transitions

## Part 4: Implementing Flexbox and Grid Examples

Create a new file at `app/flexgrid/page.tsx` with the following code:

```typescript
import React from "react";

export default function page() {
  return (
    <div className="space-y-8 p-4">
      {/* Flex Container Example
          - container mx-auto: centers the container and sets max-width
          - flex flex-row: creates horizontal flexbox layout
          - space-x-4: adds horizontal spacing between flex items
          - p-4: adds padding
          - bg-gray-100: adds background color for visibility */}
      <div className="container mx-auto p-4 flex flex-row space-x-4 bg-blue-100 rounded-lg">
        <div className="border flex-1 text-center p-4 bg-gray-100 rounded-lg shadow">
          Flex Item 1
        </div>
        <div className="border flex-1 text-center p-4 bg-gray-100 rounded-lg shadow">
          Flex Item 2
        </div>
        <div className="border flex-1 text-center p-4 bg-gray-100 rounded-lg shadow">
          Flex Item 3
        </div>
      </div>

      {/* Grid Container Example
          - grid: enables grid layout
          - grid-cols-1: 1 column on mobile
          - md:grid-cols-2: 2 columns on medium screens
          - lg:grid-cols-3: 3 columns on large screens
          - gap-4: adds spacing between grid items
          - container mx-auto: centers the container */}
      <div className="container mx-auto grid grid-cols-1 md:grid-cols-2 lg:grid-cols-3 gap-4">
        <div className="p-4 bg-gray-100 rounded-lg shadow text-center">
          Grid Item 1
        </div>
        <div className="p-4 bg-gray-100 rounded-lg shadow text-center">
          Grid Item 2
        </div>
        <div className="p-4 bg-gray-100 rounded-lg shadow text-center">
          Grid Item 3
        </div>
        <div className="p-4 bg-gray-100 rounded-lg shadow text-center">
          Grid Item 4
        </div>
        <div className="p-4 bg-gray-100 rounded-lg shadow text-center">
          Grid Item 5
        </div>
        <div className="p-4 bg-gray-100 rounded-lg shadow text-center">
          Grid Item 6
        </div>
      </div>

      {/* Responsive Container Example
          - mx-auto: centers the container
          - max-w-7xl: sets maximum width
          - p-2: base padding
          - sm:p-8: padding on small screens
          - lg:p-16: padding on large screens
          - bg-blue-100: background color for visibility */}
      <div className="mx-auto max-w-7xl p-2 sm:p-8 lg:p-16 bg-blue-100 rounded-lg text-center">
        Responsive container with adaptive padding
      </div>

      {/* Flex Container with Wrap Example
          - flex flex-wrap: allows items to wrap to next line
          - justify-center: centers items horizontally
          - items-center: centers items vertically
          - gap-4: adds uniform spacing between items */}
      <div className="container mx-auto p-4 flex flex-wrap justify-center items-center gap-4 bg-purple-100 rounded-lg">
        {[1, 2, 3, 4, 5].map((item) => (
          <div
            key={item}
            className="w-48 h-24 flex items-center justify-center bg-white rounded-lg shadow"
          >
            Flex Wrap Item {item}
          </div>
        ))}
      </div>

      {/* Grid with Auto-fit Example
          - grid-cols-[repeat(auto-fit,minmax(200px,1fr))]: creates responsive columns
          - auto-fit automatically fits as many columns as possible
          - minmax(200px,1fr) sets minimum and maximum column width
          - gap-6: adds larger gap between items */}
      <div className="container mx-auto p-4 grid grid-cols-[repeat(auto-fit,minmax(200px,1fr))] gap-6 bg-green-100 rounded-lg">
        {[1, 2, 3, 4].map((item) => (
          <div
            key={item}
            className="aspect-square bg-white rounded-lg shadow p-4 flex items-center justify-center"
          >
            Auto-fit Grid Item {item}
          </div>
        ))}
      </div>
    </div>
  );
}

```

Let's break down the key concepts used in this page:

### 1. Flex Container Example
```typescript
className="container mx-auto p-4 flex flex-row space-x-4"
```
- `flex flex-row`: Creates a horizontal flexbox layout
- `space-x-4`: Adds horizontal spacing between flex items
- `flex-1`: Makes each item grow equally

### 2. Grid Container Example
```typescript
className="grid grid-cols-1 md:grid-cols-2 lg:grid-cols-3 gap-4"
```
- `grid`: Enables CSS Grid layout
- `grid-cols-1`: One column on mobile
- `md:grid-cols-2`: Two columns on medium screens
- `lg:grid-cols-3`: Three columns on large screens
- `gap-4`: Adds uniform spacing between grid items

### 3. Responsive Container Example
```typescript
className="mx-auto max-w-7xl p-2 sm:p-8 lg:p-16"
```
- `max-w-7xl`: Sets maximum width
- `p-2`: Base padding for mobile
- `sm:p-8`: Increased padding on small screens
- `lg:p-16`: Larger padding on large screens

### 4. Flex Container with Wrap Example
```typescript
className="flex flex-wrap justify-center items-center gap-4"
```
- `flex-wrap`: Allows items to wrap to next line
- `justify-center`: Centers items horizontally
- `items-center`: Centers items vertically
- `gap-4`: Adds uniform spacing between items

### 5. Grid with Auto-fit Example
```typescript
className="grid grid-cols-[repeat(auto-fit,minmax(200px,1fr))] gap-6"
```
- `auto-fit`: Automatically fits as many columns as possible
- `minmax(200px,1fr)`: Sets minimum and maximum column width
- `gap-6`: Adds larger gap between items

## Part 6: Understanding Key Concepts

```css
:root {
  --background: #ffffff;
  --foreground: #171717;
  --color-primary: #3b82f6;
  --color-secondary: #10b981;

```
These CSS variables can be referenced throughout your application, making it easy to maintain consistent colors and switch themes.

### 2. Color System
- Primary colors (blues) for main actions and emphasis
- Secondary colors (greens) for supporting elements
- Grayscale colors for text and backgrounds

### 3. Component Patterns
- Consistent padding and margin spacing
- Rounded corners (rounded-lg)
- Hover states with transitions
- Shadow effects for depth
